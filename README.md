# BLC Device Lab

> **Project status: sunset / discontinued.**

BLCCoreStudio has decided to end active development of BLC Device Lab as part of a deliberate reduction in project count and maintenance load.

The project explored a local Android physical-device workspace built around ADB, scrcpy, diagnostics, capture, installation and repeatable device workflows. The existing implementation and history are preserved for reference, but **no further feature development or routine maintenance is planned**.

This repository may later be made private or removed after the portfolio cleanup is complete.

## Why development ended

The project overlapped with mature Android-device tooling and would require substantial ongoing cross-platform and dependency maintenance to become a clearly differentiated product. BLCCoreStudio is instead concentrating development time on a smaller set of maintained projects.
